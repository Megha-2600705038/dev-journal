# Variable Declaration
> No command for declaring a variable and a variable is created when you assign a value to it.

Example:
```python
x = 5
y = 'Megha'
```
> Do not need to be declared with any data type, and can change type after they have been set.

Example:
```python
x = 10
x = 'Megha'
print(x)
```

> If you want to specify the data type, then

Example:
```python
x = int(3)
y = str("Megha")
z = float(5)
```

> To get the data type of a function use type() function.

Example:
```python
x = 4
print(type(x))
```

> Variable names are case sensitive(age, Age and AGE are 3 different variables).
> Allows to assign values to multiple variables in a single line.
> Allows to assign same value to multiple variable in a single line.

Example:
```python
a, b, c = 10, 20, 30
f = g = i = "Megha"
```

> In print() function you can put multiple variable separated by + operator or comma.

Example:
```python
x = 'Orange'
y = 'Apple'
Z = Mango'
print(x, y, z)
print(x + y + z)
```
note: add a space in print() function
