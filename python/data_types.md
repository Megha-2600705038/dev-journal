# Data Types
> Data types define what kind of value a variable can hold.
> Variables can store different data types, and different types can do different things.

# Built-in Data Types
1. Numbers
> int - integer, a positive or negative number without decimals
> float - floating number, positive, negative, number with decimals or a scientific number
> complex - written with j as a imaginary part

 # Conversion
Example:

```python
x = 5
y = 3.6
z = 2j
# convert int to float
a = float(x)

# convert int to complex
 b = complex(x)

print(a)
print(b)
```

# Random 
> Does not have a random() function, but has a built in module random to make random numbers.
Example:

```python
import random

print(random.randrange(1, 20))
```
