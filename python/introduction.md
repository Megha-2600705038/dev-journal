# Python Indentation
> a space at the beginning of the code line. use to indicate a block of code.

Example:
```python
if 10>2:
  print("10 is large")
```

> use same number of spaces in the same block of code.
> do not need to use a semicolon at the end of a statement.
> text must be inside a double or single quotes.

> to print multiple words on the same line use "end" parameter.

Example:
```python
print("Hello", end = " ")
print("World!")
```

> also can do math inside the print function.

Example:
```python
print(3+7)
```

